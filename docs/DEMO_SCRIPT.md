# 3–5 minute demo script

Use only synthetic documents. Rehearse the browser flow before recording; do not present mocked extraction as a live Gemini call.

| Time | Show | Explain |
|---|---|---|
| 0:00–0:25 | Overview and requests | Small accounting firms need one place to collect client invoices and know what is missing. |
| 0:25–1:00 | Add a client and create a monthly request | Real persisted client-period checklists, due dates and derived progress. |
| 1:00–1:45 | Share link, then open it in a private/mobile browser | Client uploads without an account. Upload a supplied synthetic PDF; show status and mark the item finished. |
| 1:45–2:50 | Review a wrong-total sample | Show original versus extracted fields. INV-002 gives the exact discrepancy. Correct the total and approve, or reject with a reason and show replacement on the client portal. Explain which extraction adapter is active. |
| 2:50–3:25 | Export approved CSV | Only approved data is exported, including edited fields. Open in Excel; show headers and amounts. |
| 3:25–3:55 | Reminders and request completion | Explain pauses, quiet hours and delivery logs. Demonstrate actual email only when a provider is connected; otherwise demonstrate the manual WhatsApp link without claiming delivery. |
| 3:55–4:20 | Source/architecture briefly, final product | Tenant isolation, private files, durable jobs, concurrency protection and human review. Return to the working application. |

For final submission record the deployed application, not only localhost. Keep the repository tour short. The human records narration, verifies sharing permissions, and completes the official form.
